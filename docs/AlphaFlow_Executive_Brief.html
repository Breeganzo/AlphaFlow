1. Executive Summary

AlphaFlow is a production-grade quantitative research system that extracts trading signals from market microstructure data, validates them with machine learning, and presents results through a real-time dashboard. It demonstrates Kyndryl's capability to deliver AI-powered financial analytics for capital markets clients — from raw market data to actionable insight, with full auditability.

What makes this different: The trading signal is 100% deterministic and auditable. The AI (LLM) writes explanations only — it never decides a trade. This separation is a regulatory and compliance requirement that most competing solutions fail to enforce.

2.2 AI / Rules / ML Boundary (the key differentiator)

Financial regulators (MiFID II, SEC) require that automated trading decisions be auditable. AlphaFlow enforces a strict three-layer separation:

Deterministic (Auditable)

  • Rules layer: All microstructure math — OFI, Kyle's λ, Amihud, spreads. Pure functions with unit tests against hand-computed reference values.
  • ML layer: LightGBM walk-forward regressor. Deterministic given the same data. SHAP explains every prediction.
  • Signal classification: Two-tier cross-sectional rank + FDR correction. No randomness, no LLM involvement.

AI (Narrative Only)

  • Groq LLM at exactly 3 call sites
  • Receives computed numbers as context
  • Generates English explanations of signals
  • Temperature ≤0.2, grounded in live DB values
  • Never decides BUY/SELL/HOLD
  • Can be removed without changing any signal

We report real numbers, not inflated ones. The cross-sectional average |IC| is ~1.4% and 0 of 50 tickers survive multiple-testing correction. 7.1 Why the IC is Low (and What Fixes It)

The limitation is data resolution, not methodology. Our OFI proxy classifies each entire hourly bar's volume as buy or sell based on close vs. open. Real OFI (Chordia et al. 2002) classifies each individual trade using Lee-Ready tick rules. With tick-level data (~$200/month), the same pipeline architecture would target IC 4–8%.
